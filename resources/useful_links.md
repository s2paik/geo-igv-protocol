# Useful Links

Curated collection of tools, databases, and learning resources
referenced throughout this repository.

---

## Genome browsers and visualization

| Tool | URL | What it does |
|------|-----|-------------|
| IGV Desktop | https://igv.org/doc/desktop/ | Local genome browser for viewing BAM, bigWig, BED, GTF files |
| UCSC Genome Browser | https://genome.ucsc.edu/ | Web-based genome browser with hundreds of public tracks |
| Ensembl Genome Browser | https://ensembl.org/ | Web-based browser with comprehensive gene annotation |
| UCSC In-Silico PCR | https://genome.ucsc.edu/cgi-bin/hgPcr | Find genomic location of PCR primer pairs |

## Data repositories

| Database | URL | What it contains |
|----------|-----|-----------------|
| NCBI GEO | https://www.ncbi.nlm.nih.gov/geo/ | Processed expression data, bigWigs, supplementary files |
| NCBI SRA | https://www.ncbi.nlm.nih.gov/sra | Raw sequencing reads (FASTQ) |
| GEO2R | https://www.ncbi.nlm.nih.gov/geo/geo2r/ | Online differential expression analysis (no coding needed) |
| ArrayExpress | https://www.ebi.ac.uk/arrayexpress/ | European equivalent of GEO |
